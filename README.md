# VPN Infra

Отдельный репозиторий для инфраструктуры VPN.

Здесь хранятся:
- шаблоны конфигураций серверов
- шаблоны env-файлов
- описания маршрутов entry -> exit
- deploy/ops-документация
- вспомогательные infra-скрипты

Здесь не хранятся:
- реальные токены
- приватные ключи
- пароли
- боевые `.env`
